# LCCC — coming soon

Placeholder page for https://lccc.lu while the new website is developed at https://beta.lccc.lu
(repository: [schto173/lcccWeb](https://github.com/schto173/lcccWeb)).

Only the `site/` folder is served.

## Pages and design

The pages are generated by `python build.py` (edit the texts there, not the HTML). They use the main
website's design: `site/style.css`, `site/icons.svg` and `site/img/` are copies from the website repository
(`site/` in schto173/lcccWeb). After design changes there, copy those files again and run `python build.py`.

## Server

Stop the old lccc.lu containers first (`docker compose down` in their folder), then:

```sh
git clone https://github.com/schto173/lccc-placeholder
cd lccc-placeholder
docker compose up -d
```

Update the page later with `git pull` in that folder.

## Vendor and sponsor forms

`site/vendors.html` (the target of the flyer QR code, `flyer/`) and `site/sponsors.html` each have a short form.
The small `api` service saves sign-ups in `data/vendor-interest.json` and `data/sponsor-interest.json` on the
server (not in git), emails each sign-up to `NOTIFY_TO` and sends the person a confirmation.

Create a `.env` next to `docker-compose.yml` with the same mail settings as on beta:

```sh
NOTIFY_TO=royalfamilyeventing+web@gmail.com
SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_USER=xxxxxx@smtp-brevo.com
SMTP_PASS=xsmtpsib-...
MAIL_FROM=notifications@lccc.lu
MAIL_FROM_VENDORS=vendors@lccc.lu
MAIL_REPLY_TO=royalfamilyeventing+web@gmail.com
```

then `docker compose up -d`. To see all sign-ups: `cat data/vendor-interest.json data/sponsor-interest.json`.
The privacy page (`site/privacy.html`) promises to delete them after the vendor selection and sponsor
planning for LCCC 2027.
